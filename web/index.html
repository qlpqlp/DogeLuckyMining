casino Lucky Nonce Search Strategy

Sequential: Test nonces 0, 1, 2, 3... (full coverage)
Forward: Start from calculated point, increment forward (wraps at 0xFFFFFFFF)
Backward: Start from calculated point, decrement backward (wraps at 0)
Calculated: Start nonce = Version XOR Timestamp XOR Bits (deterministic per block)
Random: Start nonce = current time (pseudo-random)
Stride Mode: Each thread tests nonces with stride = threadCount
Example (4 threads): Thread 0 tests 0, 4, 8, 12... Thread 1 tests 1, 5, 9, 13...
Range Mode (unchecked): Each thread gets a unique nonce range (default, recommended)
